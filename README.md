# XYZ Store Sales Dashboard 📊

An interactive **Power BI** dashboard built to analyze and compare monthly sales performance for XYZ Store, with a focus on **November vs. December** data.

## Overview

This dashboard provides a consolidated view of sales, orders, and profit metrics, enabling quick month-over-month comparisons and deeper drill-downs by category, segment, and product performance.

## Features

- **KPI Cards** — Current month Sales, Orders, and Profit with % change indicators vs. the previous month
- **Day & Month Trend Chart** — Sales broken down by day of week (Mon–Sun) across November and December
- **Category Breakdown** — Order count and order % by category (Furniture, Office Supplies, Technology) with donut chart
- **Segment Breakdown** — Order count and order % by customer segment (Home Office, Corporate, Consumer) with donut chart
- **Top 5 Products** — Best-performing products by sales, orders, and profit
- **Bottom 5 Products** — Lowest-performing products by sales, orders, and profit
- **Slicers** — Filter data by Mode of Shipping and Sub-Category
- **TMDL View** — Tabular Model Definition Language view for the underlying data model

## Dashboard Preview

The dashboard includes two views:
1. A **styled dark-theme dashboard** with custom cards, charts, and tables
2. A **summary/report view** with simplified visuals for quick reporting

## Tech Stack

- **Power BI Desktop** — Data modeling, DAX measures, and visualization
- **TMDL (Tabular Model Definition Language)** — Data model definition

## Key Metrics Tracked

| Metric | Description |
|---|---|
| Sales | Total monthly sales value |
| Orders | Total number of orders placed |
| Profit | Total monthly profit |
| Order % | Share of orders by category/segment |
